Estructura del Frontend:
(├──, └──, and │) no me quiten los séimbolos :c
src/
├──adapters (encargado del adaptador de la API en Front)
├──assets (Imagenes y demas media que su utiliza en la app)
├──components (Texto, botone, inputs, entre otros)
├──hooks (Estados de la API en la aplicación)
├──layout (Plantilla donde se ubicaran las páginas)
├──page (Diseño de las páginas)
│  ├──recover (Diseño de las páginas de recuperar contraseña)
├──services (Los servicios de la API)
├──utils (Funciones que se reutilizan a lo largo de la app)
