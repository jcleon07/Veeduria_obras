## Project

**Construction Works Oversight Website (Bogotá)** — a web platform that centralizes information about active construction sites in Bogotá (progress, delays, budget, contractor, and mobility impact), allowing citizens to consult, rate, comment on, and file oversight actions regarding these works.

## Deliverable

This folder contains Workshop 1, corresponding to the Delivery #1 — Analysis phase of the course project: functional and non-functional requirements, user stories with acceptance criteria, and the user story map used for release planning.

| File | Description |

## Document sections

The PDF (`ENTREGA_1_-_ANALISIS.pdf`) is organized as follows:

1. **Requirements Documentation** — 30 functional requirements (FR_01–FR_30) and 15 non-functional requirements (NFR_01–NFR_15), each with ID, name, description, category (non-functional only), priority, and dependencies.
2. **User Stories** — 25 user stories (US-01–US-25) covering visitor, registered citizen, and administrator roles.
3. **User Story Mapping** — visual map organizing the user stories by user activity (backbone) and grouping them into three releases (MVP/walking skeleton, participation and search, insights and extras), with cross-cutting non-functional requirements shown per release.
4. **Use of Artificial Intelligence** — declaration of how Claude (Anthropic) was used as a support tool during the analysis phase.
5. **References** — sources cited throughout the requirements (applicable Colombian laws) and external references used for methodology.

## Traceability

Every functional requirement (FR) is covered by at least one user story, referenced under each story's "Related Requirements" field. Non-functional requirements (NFR) are linked either to the functional requirements they constrain or, in the user story map, shown as cross-cutting requirements delivered alongside each release.
